# L-i-t-e

Веб-шутер от первого.

## Управление в игре

| Действие                        | Управление                         |
| ------------------------------- | ---------------------------------- |
| Захват мыши / старт             | Клик по экрану игры (Pointer Lock) |
| Осмотр                          | Мышь                               |
| Вперёд / назад / влево / вправо | `W` `A` `S` `D`                    |
| Прыжок                          | `Space`                            |
| Стрельба                        | ЛКМ (удерживать)                   |
| Выход из захвата мыши           | `Esc` (стандарт браузера)          |

После клика включается музыка (если браузер позволяет audio context).

## Геймплей

### Цель
Пройти уровни кампании: найти **ключ / цель**, открыть связанные **двери**, дойти до выхода. 

В конце показывается время прохождения.

### Здоровье
- Шкала HP внизу слева (в процентах)
- Урон от врагов и опасных зон уменьшает HP
- **Аптечки** восстанавливают здоровье
- При низком HP полоска краснеет и мигает
- После смерти - короткое «падение» камеры и респаун

### Оружие
Пулемёт от первого лица. ЛКМ - огонь. 

При стрельбе ствол вращается.

### Свет
На карте есть **фонарик**. 

Пока он не подобран, сектор тёмный. 

После подбора свет идёт за игроком (динамические тени).

### Враги
| Тип          | Описание                                        |
| ------------ | ----------------------------------------------- |
| **Враг**     | Наземный солдат в броне, патрулирует и стреляет |
| **Летающий** | Дрон/вертолёт с вращающимися лопастями          |
| **Группа**   | Несколько врагов сразу                          |

Убийства иногда дропают аптечки. 

На повышенной сложности враги опаснее и появляются чаще.

### Объекты на карте
| Объект       | Назначение                           |
| ------------ | ------------------------------------ |
| `enemy`      | Наземный враг                        |
| `flying`     | Летающий враг                        |
| `many`       | Группа врагов                        |
| `health`     | Аптечка                              |
| `flashlight` | Фонарик                              |
| `goal`       | Ключ / цель уровня                   |
| `door`       | Дверь (открывается связанным ключом) |

### Сложность
После первого прохождения кампании включается более жёсткий режим (`difficulty`): сильнее урон, агрессивнее враги, больше спавна.

### Графика
- WebGL2, процедурные текстуры, тени, bloom, сглаживание краёв
- Разрешение подстраивается под экран
- При просадках FPS качество может автоматически снизиться

## Редактор карты (2D + 3D)

Открывается кнопкой **Editor** в меню. Сохраняет тот же JSON-формат кампании (`regions` / `objects` / `player`).

### Вид
| Режим     | Описание                     |
| --------- | ---------------------------- |
| **2D**    | Классический план сверху     |
| **Split** | 2D и 3D рядом (по умолчанию) |
| **3D**    | Только WebGL-превью          |

### Камера 3D
| Действие                    | Управление                   |
| --------------------------- | ---------------------------- |
| Orbit                       | Alt + ЛКМ или средняя кнопка |
| Fly look                    | ПКМ + движение мыши          |
| Fly move                    | WASD / QE в fly-режиме       |
| Zoom                        | Колёсико                     |
| Focus selection             | `F`                          |
| Справка по горячим клавишам | `?`                          |

### Инструменты
- Режимы: Select, Region, Object, Player, Measure (`1`-`5`)
- Примитивы: box room, corridor, ramp
- Extrude региона (`E`), merge, split edge, snap вершины
- Multi-select объектов: Shift+клик; align / distribute / snap to grid/floor
- Play from here: тест уровня со спавном в позиции 3D-камеры
- Outliner, texture browser, bookmarks камеры, notes/tags уровня
- Section plane (Z) + ghost mode для многоэтажности
- Черновики в `localStorage` + панель восстановления
- Валидация: высота, пары goal/door, overlap, unreachable; клик по issue  -> focus

### Файлы
Черновик автосохраняется в браузере. Для игры: **Download JSON** / **Apply to game** и положите файл в `maps/`.
